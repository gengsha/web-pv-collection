# 风格构成说明：思纬星图 · 推理星座 (Thought Constellation)

## 1. 风格概述 (Style DNA)

* **核心理念**：将 Qwen / QwQ 的深度推理过程（Deep Reasoning）拟喻为一次深空天文观测——思维的每一步都是一颗被点亮的星，推理链在夜空中逐段延伸，最终连成闭合的星座。页面即一座「思维观测站」。
* **视觉情绪**：冷静、精密、克制、深空寂寥中带着一点诗意的科学感。没有炫技式的高饱和光斑，只有藏蓝深空、青白星点与一次珍贵的金色「顿悟」。
* **设计原则**：星图是灵魂（Canvas 三阶段：星点闪烁 → 连线生长 → 顿悟爆亮）；文本与星点严格联动（节点亮起 ⇔ 推理步骤浮现）；装饰全部服务于「观测」语境（赤经/赤纬坐标、十字准星、刻度线）。
* **适用场景**：推理型大模型个人主页、Chain-of-Thought 能力展示、评测成绩发布页、科研感产品官网。

## 2. 色彩令牌 (Design Tokens)

```css
:root {
  /* 深空基底 */
  --bg-deep: #050816;                  /* 深空藏蓝：全页底色 */
  --bg-panel: #0A101F;                 /* 面板藏蓝：观测面板基底 */
  --bg-glass: rgba(10, 16, 31, 0.62);  /* 玻璃观测面板 */

  /* 星光与连线 */
  --star-white: #CFF6FF;               /* 星点青白：星核/高光文字 */
  --line-cyan: #38BDF8;                /* 连线青：推理链主色 */
  --line-teal: #4FD1C5;                /* 辅连线青绿：渐变末端/点缀 */
  --gold: #F5C86E;                     /* 「顿悟」金：最终节点/结论 */

  /* 边框冷光 */
  --border-cold: rgba(120, 170, 220, 0.16);   /* 1px 冷光边 */
  --border-glow: rgba(56, 189, 248, 0.45);    /* 悬停辉光边 */

  /* 文本层级 */
  --text-main: #E6EDF3;                /* 主文本 */
  --text-dim: #6B7A90;                 /* 弱化文本/注释 */
}
```

**用色纪律**：青白与青系承担 90% 的发光；金色只在「顿悟节点、最终结论、最高分星等」三处出现，保持稀缺性；禁止引入紫/粉等高饱和极光色。

## 3. 排版与字体系统 (Typography)

* **Google Fonts 引入**：
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Outfit:wght@300;400;500;600;700&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
  ```
* **主标题 (Display)**：`Outfit` 600/700，字距 `-0.03em`；中文回落系统黑体。关键词用「青→青绿」低饱和渐变剪裁，拒绝彩虹渐变。
* **正文 (Body)**：`Outfit` 300/400，行高 `1.65`，颜色 `#6B7A90`（弱）/ `#E6EDF3`（主）。纤细字重是「冷静感」的来源。
* **数据/坐标/日志 (Mono)**：`JetBrains Mono` 400/500，用于赤经赤纬标签（`RA 05h34m` / `DEC +22°00′`）、状态灯（`TRACKING`）、推理日志，字号 0.65~0.85rem，字距 `0.06em~0.12em`，营造仪器读数感。

## 4. 视觉材质与构件法则 (Materials & Geometry)

* **全屏深空 Canvas（页面灵魂）**：固定铺满视口的 `#050816` 星空画布——星点以不同周期正弦闪烁，偶发流星沿对角线划出渐隐尾迹，鼠标靠近的星点会被点亮放大。
* **玻璃观测面板 (Observation Panel)**：
  ```css
  background: rgba(10, 16, 31, 0.62);
  backdrop-filter: blur(18px);
  -webkit-backdrop-filter: blur(18px);
  border: 1px solid rgba(120, 170, 220, 0.16);   /* 1px 冷光边 */
  border-radius: 18px;
  box-shadow: 0 24px 48px -18px rgba(0, 0, 0, 0.65),
              inset 0 1px 0 rgba(207, 246, 255, 0.06);
  ```
* **星坐标标注 (Coordinate Chips)**：所有关键构件附带赤经/赤纬式小标签——等宽字体、细描边、低对比，如 `RA 05h34m`、`DEC +22°00′`、`EPOCH J2026.0`。
* **十字准星与刻度 (Reticle & Ticks)**：面板对角以 `+` 十字标记锚定；面板头部铺设细刻度条（`repeating-linear-gradient` 每 28px 一道 1px 刻度）；Hero 区置一个缓慢自转的虚线圆形目镜（46s/圈）。
* **推理星座画布**：观测面板内嵌星图视口，内部绘制边缘刻度、四角十字、微尘星点；推理节点附带坐标标注。

## 5. 动效物理与微交互 (Motion & Dynamics)

* **推理链生长动画（核心三阶段）**：点击「推演」后——①节点逐颗点亮：星核以 `easeOutCubic` 绽开并伴随一次扩散光环；②连线逐段生长：二次贝塞尔弧线在 700ms 内从上一颗星画向下一颗，生长端点带亮斑；③顿悟爆亮：最终节点以金色粒子迸发 + 金色扩散环 + 十字星芒收束，全链闭合。节点间隔约 1.15s，全程约 7s，节奏如逐帧观测。
* **文本-星点联动**：侧栏「思维碎片」中，每个节点对应一条推理步骤；节点点亮的同一时刻，对应文本以 `translateX(10px) → 0` + 透明度浮现。
* **光标引力点亮**：鼠标靠近背景星点（< 130px）或星图节点时，星点平滑增亮放大，离开后阻尼回落。
* **流星偶发**：每 4~9 秒随机一次，尾迹使用线性渐变（青白头亮尾虚），生命周期 0.7~1.1s，同屏至多 2 颗。
* **星等亮度条**：评测成绩以「视星等」呈现，进入视口时亮度条以 `cubic-bezier(0.22, 1, 0.36, 1)` 在 1.6s 内生长，末端凝聚一颗亮点。
* **过渡基准曲线**：`cubic-bezier(0.22, 1, 0.36, 1)`（平稳推进、柔和落定），禁止弹跳类过冲曲线。
